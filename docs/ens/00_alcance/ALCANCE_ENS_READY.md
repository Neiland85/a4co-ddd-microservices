# Alcance ENS-ready

Este paquete documenta una preparación técnica y operativa para alineamiento ENS/CCN-STIC.

## Alcance incluido

- Baseline estático del monorepo.
- Validación de toolchain.
- Lint preview sin errores bloqueantes.
- Tests preview OK.
- Build preview OK.
- Runtime beta incremental:
  - API Gateway.
  - Order Service.
  - Inventory Service.
  - Postgres.
  - NATS.

## Alcance excluido por ahora

- Certificación ENS formal.
- Declaración de conformidad ENS.
- Auditoría externa.
- Auth Service en runtime beta incremental.
- Product Service en runtime beta incremental.
- Payment Service en runtime beta incremental.
- Cumplimiento eIDAS/firma cualificada.
- Cumplimiento NIST/FIPS formal.

## Estado

El sistema queda en estado de preparación inicial ENS-ready, no certificado.
