# No certificación ENS

Este proyecto no debe presentarse como certificado ENS.

El trabajo actual consiste en:

- preparación técnica;
- hardening progresivo;
- generación de evidencias;
- matriz de controles;
- documentación operativa;
- reducción de gaps;
- preparación para posible auditoría futura.

## Frases permitidas

- Arquitectura preparada para alineamiento ENS/CCN-STIC.
- Baseline técnico ENS-ready.
- Evidencias técnicas reproducibles.
- Preparación para evaluación de controles.

## Frases prohibidas

- Cumple ENS.
- Certificado ENS.
- Certificado CCN-STIC.
- Aprobado por el CCN.
- Válido automáticamente para administración pública.
- Cumple ENS Medio/Alto.
